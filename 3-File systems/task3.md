# Продолжаем

4 скрина

1. Выведите содержимое fstab. Что хранится в fstab?
    cat /etc/fstab 
    В fstab хранится информация о файловых системах, которые должны быть смонтированы при загрузке системы. Каждая строка описывает ус-во, точку монтирования, тип файловой системы и параметры монтирования.

2. Добавьте в виртуальную машину ещё один диск
3. Узнайте как ситема видит ваш диск - выведите информацию о блочных устройствах
    lsblk

4. С помощью полученной информации создайте на диске таблицу разделов и фаловую систему ext4
   fdisk /dev/sdb 
   mkfs.ext4 /dev/sdb

   ![Пункт 1-4](<3.3.1.png>)

5. Примонитруте диск в каталог /mnt
    mount /dev/sdb /mnt

6. Зайдите в каталог и создайте там файлы
    cd /mnt
    touch file1.txt file2.txt

   ![Пункт 4-6](<3.3.2.png>)

7. Отмонтируйте диск и проверьте остались ли файлы
    umount /mnt
    ls /mnt

   ![Пункт 7](<3.3.3 линукс.png>)

8. Сделайте так чтобы диск автоматически подключался при загрузке систем ( добавьте информацию о нём с fstab)
    nano /etc/fstab
    Добавляем строку в /etc/fstab:
    /dev/sdb1 /mnt ext4 defaults 0 0

9. Проверьте корретность записанных в fstab данных перед перезагрузкой
    cat fstab

10. Перезагрузите систему и убедитесь что диск был подключён к системе
    reboot
    lsblk
